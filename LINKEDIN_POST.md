# LinkedIn post options

## Option 1 — Story style (recommended)

I rebuilt my portfolio from scratch, and this time I obsessed over the details. 🌸

I'm a software engineer, and my old portfolio was clean, correct and… forgettable. So I designed one that feels professional and still has personality.

What's inside:

🪢 A pull-rope for dark mode: yank the cord and the new theme spreads out from the knob as a circle, with a soft sound
🪧 A wooden "HIRE ME" board on the other rope that swings when you hover it
🐾 A row of hopping pixel animals and floating hearts at the bottom, plus a live GitHub contribution graph
⌨️ A typewriter line, a filterable tech stack where every tech plays its own note on hover, and a clean projects / designs / blog structure
📱 Fully responsive: laptop, tablet, phone

Built with React, Vite and Tailwind CSS. The sounds are generated with the Web Audio API (no audio files) and the theme reveal uses the View Transitions API.

What I learned:
→ Small motion and sound details make a site feel finished
→ Typography and spacing do more for "professional" than any effect
→ Building it from scratch teaches you the platform

## Posting tips

- Add a 10–15 second screen recording as the post media: switch the theme, tap the avatar, scroll the tech stack. Show the phone too. Video gets far more reach than a link.
- Put the link in the first comment and write "link in comments" in the post if you want more reach.
- Post Tue–Thu, 8–10 AM IST.
- Replace the bracketed placeholders and delete anything that isn't true for you.
